## 0. 콘셉트

| 항목 | 값 |
|---|---|
| 콘셉트 | **"말을 한 겹씩 벗겨낸다"** — 페이퍼컷 레이어 |
| 장면 | 노란 하늘 + 겹겹이 파란 계곡 + 일하는 작은 종이 사람들 (회의 · 노트북 · 자전거 퇴근 · 엎드려 카드 읽기) |
| 구조 | iOS 네이티브 골격(탭바·리스트·버튼 크기) + 토스식 정돈 + 종이 그림자 + **리퀴드 글래스** |
| 폰트 | **Pretendard 하나만.** 세리프·장식 폰트 금지 (Instrument Serif는 제거함) |
| 아이콘 | SF Symbols 벡터 (`figma-export/sf-svg/`, 채움형 · semibold) |
| 화면마다 | 팔레트를 바꿔 단조롭지 않게 (sun · teal · tan · ocean · coral · ink) |
| 보이스 | 판교 사람을 놀리지 않고 같이 웃는다. 짧은 구어체("~해요"). 동작 이름은 **"해석"** |

## 7. 브랜드 마크 (`brand.py`)

| 요소 | 규칙 |
|---|---|
| 심볼 `mark()` | 120×120 기준. **겹친 종이 말풍선 3장** (뒤 coral → 가운데 peach → 앞 ocean), 왼쪽 아래 꼬리 |
| 벗겨진 모서리 | 앞장 오른쪽 위가 벗겨져 peach 속지 + 흰 접힌 면 |
| 물음표 | 흰 선(굵기 9, 둥근 끝) + **점은 sun `#F7C948`** |
| 그림자 | `dx -2 dy 4 blur 3.5 opacity .28` (40px 미만 아이콘은 생략) |
| 워드마크 `wordmark()` | **"뭔말인교?"** 800 · 자간 -0.02em · ink, **물음표만 ocean** |
| 앱 아이콘 `app_icon()` | radius = 크기×0.225, 크림 그라디언트(`#FBEBC0 → #F7F3EC`) 위 심볼 86% |
| 로크업 `lockup()` | 심볼(글자 1.5배) + 워드마크, 간격 = 글자 0.3배. 어두운 바탕은 흰 워드마크 |

## 8. Figma 캡처 안전 CSS 규칙

HTML → Figma 캡처(`generate_figma_design`)에서 깨지는 패턴과 대응. SuperDesign 미리보기는 HTML과 같아서 문제없음.

| # | 깨지는 패턴 | 증상 | 대응 (코드 위치) |
|---|---|---|---|
| 1 | 내비바의 **빈 `<div>`** | 사라져서 오른쪽 버튼이 왼쪽으로 붙음 | 빈 자리도 **크기 지정** `44×44` (`build_v5.py`의 `E`) + `.right{margin-left:auto}` |
| 2 | `box-shadow: inset …` 테두리 | 테두리가 사라짐 | **실제 `border`** 사용 (`.check{box-shadow:none;border:2px solid #D8D2C8}`) |
| 3 | `top`만 준 absolute 시트 | 높이가 내용만큼만 잡힘 | **`height` 명시** (예: `top:72px;height:780px`, `top:290px;height:562px`) |
| 4 | flex로 쪼갠 워드마크 | 텍스트 레이어가 갈라져 물음표가 붙음 | **인라인 span 하나** 안에 색만 다른 `<span>` (`brand.wordmark`) |
| 5 | `<mark>` 인라인 형광펜 | 경계 공백이 사라짐 | **단어 블록**으로 변환 `.wf > .tk > .hl` (`build_v5.py`의 `nbsp_marks`) |
| 6 | 여러 겹 radial-gradient | 약하게 나옴 | 단색·선형 그라디언트 위주 |
| 7 | 폰트 | 캡처는 `Semi Bold`·`Extra Bold`로 기록 | Figma "Replace fonts"에서 `SemiBold`·`ExtraBold`로 매칭. MCP 서버 렌더에는 Pretendard가 없음(데스크톱은 정상) |

- 남은 미세 차이: W-01 첫 형광펜 앞 공백, 작은 글씨에서 형광펜 뒤 글자 1px 겹침
