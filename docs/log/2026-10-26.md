# 2026-10-26 (월) — v1.0 Day 3

## Day 3 (#3) MwonmalAPI
- 오늘 한 것: swift-openapi-generator 1.14.2 빌드 플러그인으로 계약 v1.0 43 op 생성·컴파일, `KSTDateTranscoder`(오프셋 없음=KST, 오프셋 있으면 따름, 소수 초, 엄격 파싱), 미들웨어 3개(Auth: Bearer·oauthLogin 제외·401 신호 dedupe / Retry: GET 503만 1회, Retry-After 최대 10s / Error: 공통 봉투→`MwonmalServerError`, 봉투 아니면 `HTTP_<status>`·본문 비노출). 테스트 26개, 돌연변이 3종(dedupe·GET 한정·로그인 제외)을 테스트가 잡음.
- 막힌 것과 푼 방법: Tuist가 yaml을 타깃에서 빼서 플러그인이 계약을 못 찾음 → MwonmalAPI를 로컬 Swift 패키지로(ADR-0001 개정). `ServerError`가 OpenAPIRuntime 타입과 이름 충돌 → `MwonmalServerError`. 디스크 가득 참(ENOSPC)으로 1~2h 정지 → 캐시 정리.
- 발견: 생성된 enum 디코딩이 엄격해서, 서버가 v1.0 앱이 모르는 enum 값을 보내면 응답 전체가 디코딩 실패한다 → v1.1 계약에서 enum 추가는 앱 배포 뒤에만(백로그 메모).
- 병행: 서버 레드팀(1라운드 High 2건 발견, 별도 브랜치), 온디바이스 AI·아키텍처·마케팅 조사(scratchpad 보고서, ADR-0015/0016 예정).
- 시간: 약 3h.
