# ADR-0024: 시작 연출·온보딩·움직임 프리셋 확장 — 레퍼런스 영상 3편을 앱 움직임으로 옮긴다

- 상태: 채택 (2026-10-29)
- 관련: ADR-0012(Motion 토큰), ADR-0006(넓은 화면), ADR-0016(기능 모듈), ADR-0017(색 토큰), REQ-22·REQ-03

## 맥락

- 사용자 요구(2026-10-29): "앱을 껐다 켤 때 로고는 이런 식으로", 레퍼런스 영상 3편의 분위기를 앱 인터랙션에 많이 들일 것,
  Mac 앱 디자인을 iOS 수준으로(온보딩 포함).
- 레퍼런스(사용자 폴더 `디자인 레퍼런스/앱 레퍼런스 영상/`, 저장소에 넣지 않는다):
  - V2: 앱 아이콘이 커지며 검은 실행 화면 + 로고 → 실행 화면 전체가 **찌그러지며 둥근 아이콘 타일로 접히고**, 그 뒤 첫 화면이 초점이 맞으며 나온다.
  - V1: 낮은 폴리곤 등각 세계. 장면 사이를 **카메라가 돌진(줌 + 흐림 + 디졸브)** 하며 넘어간다. 글 카드는 제자리.
  - V3: 사진 위 **초점 이동(흐림 → 선명)**, 떠다니는 **반딧불**, 윗줄 + 제목이 **줄마다 차례로** 나타남, 유리 칩, 둘레로 **퍼지는 물결**.
- Figma에는 온보딩 O-1~O-3(51:18·51:178·51:301)이 이미 있지만 앱에 없었다(ADR-0016은 Onboarding을 v1.1 모듈로 두었다).
  앱 아이콘이 없었다. Mac 로그인은 393pt 기둥이었다.
- ADR-0012는 Motion 토큰을 정했지만 코드에는 토스트 하나만 있었다.

## 결정

1. **움직임은 전부 `MwonmalUI/Motion`에서** (ADR-0012 그대로, 린트 `no_inline_animation_literal`).
   - 스프링 토큰: `paper`·`snappy`·`soft`(ADR-0012) + **`pop`(0.42/0.70)**, **`squash`(0.50/0.62)**.
     ADR-0012의 "감쇠 ≥ 0.8"에서 두 개만 예외다. `pop`은 칩·말풍선 등장, `squash`는 시작 연출 한 번에만 쓴다.
   - `MwStagger.text`(0.08초, 상한 0.6) · `.chips`(0.09초, 상한 0.9).
   - 모디파이어: `mwFocusIn`(흐림 14 → 0, 1.04 → 1), `mwRise`(18pt 아래 + 흐림 6), `mwPop`(0.4 → 1, 기울기 → 0),
     `mwSlideIn`, `mwFloat`(시간 함수, 0 → 위 → 0), `mwPulseRing`, 전환 `AnyTransition.mwDive(forward:)`.
   - `MwFireflies`: 점 12개 이하, 초당 30번, 번호로 정해지는 궤도(난수 없음).
   - `MwLaunchSplash`: 종이색 + 로고 96pt(실행 화면과 같은 첫 프레임) → 로고 튐 → 면이 132pt 타일로 접힘(squash) → 첫 화면 초점 맞춤. 1.2초, 터치를 막지 않음.
2. **끝 상태 = Figma.** 모든 움직임은 들어온 뒤 위치·크기·투명도가 원래 값이다. 계속 도는 움직임(`mwFloat`)도 0에서 시작해 0으로 돌아온다.
   그래서 화면 비교(정지 상태)는 그대로 Figma와 맞춘다.
3. **동작 줄이기**: 흐림·크기·이동 없이 0.15초 페이드. 떠다니기·물결·반딧불은 멈춘다(그리지 않음). 시작 연출은 0.25초 뒤 페이드.
4. **온보딩 O-1~O-3을 지금 넣는다** — `OnboardingFeature` 모듈(ADR-0016 이름 그대로, v1.1에서 앞당김).
   - 처음 켤 때 한 번(`UserDefaults` `MWOnboardingSeen`). 건너뛰기·시작하기 → S-01. Debug 실행 인자 `-MWResetOnboarding`으로 다시 볼 수 있다(E2E가 쓴다).
   - 그림은 S-01 히어로처럼 **레이어로 나눠** Figma에서 벡터(PDF)로 받았다: 하늘(단색·그라데이션) / 땅(가로로만 늘림) / 무대(비율 유지) / 칩·말풍선(따로 움직임).
     무대 크기 PDF를 겹치는 방식이라 393×500에서 Figma 2배 렌더와 합성 비교 차이 0(모서리 둥글림 제외).
   - 그림 위 글자(O-2 칩, O-3 알림 두 장)는 문구 카탈로그 키로 코드에서 그린다(번역 가능). 그림의 일부라 무대 배율로 크기가 바뀌고 VoiceOver에서는 읽지 않는다.
   - 넓은 화면(Mac·iPad): 왼쪽 그림 패널 + 오른쪽 글·버튼 열. Return = 다음, Esc = 건너뛰기. 옆으로 밀어도 넘어간다.
5. **Mac 로그인**: 393pt 기둥 대신 왼쪽 S-01 히어로 패널 + 오른쪽 로고·제목·버튼 열(`AuthRootView`가 `mwLayout`으로 고른다).
6. **앱 아이콘**: Figma O-3 알림 타일(51:358)과 같은 그림 — 160° #FBEBC0 → #F7F3EC 그라데이션 + "?" 말풍선 로고(51:359, 타일의 30/36).
   iOS 1024 한 장, macOS는 824 둥근 사각형 격자 10장. 실행 화면(`UILaunchScreen`) = `LaunchBackground`(종이색, 다크 #14111C) + `LaunchLogo`(96pt).

## 비용

- 돈 0, 외부 라이브러리 0(Lottie·Rive 안 씀, ADR-0012 D-24).
- 성능: 블러는 전환하는 0.5초 동안만. 반딧불은 O-3에서만 30fps Canvas 한 장. 떠다니기는 칩마다 TimelineView(보이는 쪽만).
- 앱 크기: 벡터 PDF 22개 ≈ 200KB, 아이콘 PNG ≈ 1MB.

## 대안

| 대안 | 탈락 이유 |
|---|---|
| 그림을 통짜 PNG로 | 화면 비율이 다르면 빈틈(S-01에서 겪음), 칩을 따로 움직일 수 없음 |
| `TabView(.page)` | 전환이 옆으로 미는 것 하나뿐 — V1 다이브를 못 만든다 |
| 줄 대신 단어마다 등장 | 한 Text를 단어로 쪼개면 단어 사이 간격이 Figma와 달라진다(끝 상태 ≠ Figma). 줄 단위는 Figma도 줄을 나눠 둔 자리라 그대로 맞는다 |
| 반복 애니메이션(`repeatForever`) | 멈출 때 끝 값이 꼬인다 → 시간 함수(TimelineView)로 0 보장 |

## 검증

- 단위 테스트: 스프링 토큰(일반 토큰 감쇠 ≥ 0.8, 예외 2개 명시), 스태거 상한·단조, `mwFloat` 0 → 0, 다이브 크기,
  반딧불 결정성·개수 상한, 무대 배치(Figma 크기 배율 1·원점 0, 낮은 화면 바닥 정렬), 온보딩 그림 높이(Figma 500, SE 축소, 하한 240), 문구 키.
- E2E(iOS·Mac): 온보딩 3쪽 → 시작하기 → 로그인 → 기존 흐름.
- 화면 비교: iPhone 17 Pro에서 정지 상태 스크린숏 ↔ Figma O-1~O-3.
