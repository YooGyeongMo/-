## 3. 파트별 핵심 결정 요약 (원문: `S0/{파트}.md`)
**PM** (`S0/PM.md`) — 기한·인원 고정, 범위를 자른다(PM-1). 신규 REQ 순증 +10.5일 vs 감축 −8.5일, 달력 결손 −1(9/22는 화요일, 16번 오기) → 버퍼 0. 루트 뷰만 이중 구현, 온디바이스 AI·STT는 v1.0 미포함(PM-2). AI 4트랙은 하네스+점수표+비용 모델+ADR까지(PM-3). macOS TestFlight 11/13 분리(PM-4). 협의체 1.5h 상한(PM-5). 레드팀: 파트 합산 견적이 PM의 2.5배(RT-B-01) → 합산표 1장 재작성 예정.

**PO** (`S0/PO.md`) — `cost_model.py` 3파일·표준 라이브러리(PO-1, 초안 완료). BM 기본 가설 = 무료+구독, 녹음은 유료 전용(PO-2 — 레드팀이 "가정 단가 의존"으로 가설 강등). 무료 티어 운영 규칙표: 키는 sops, `over_limit ≠ pay` 강제, 개발 예산 RPD 50%(PO-3). 사용량 입력은 DB가 진실, Amplitude는 행동 지표(PO-4). iPad = regular에서 macOS 레이아웃 그 이상 안 함, 워치는 포워딩으로 v1 가치 확보(PO-5).

**AI** (`S0/AI.md`) — 평가셋 200문장이 라우팅의 유일 근거, 필드별 채점(AI-1). 서버 라우터가 결정, 앱은 능력 보고·온디바이스 실행(AI-2). `aiModel` 규약(AI-3). **Gemini 무료 티어 약관("기밀 제출 금지·개선에 사용·인간 검토") 확인 → PO 에스컬레이션**(AI-4). Foundation Models 4096 토큰·MESSAGE 500자 한정(AI-5), MLX 숨은 플래그(AI-6), Qwen3 LoRA 우선·nanoGPT 1일(AI-7), 엔진별 데이터 흐름 표(AI-8). Apple 문서 사실 확인 12건.

**iOS** (`S0/iOS.md`) — 최소 17.0/14.0, 게이트 3층(Platform·MwonmalUI/Compat·Composition), 폴백 필요 API는 7개뿐, `@Entry`는 13+(iOS-A1·A-2·A-4 30행 전수표). Motion = 값 토큰 + 프리셋 스펙 + `@Entry var mwMotion`(iOS-B1, 타입 시그니처 포함). 화면 규칙 6-1~6-11: 고정 높이 금지, `ViewThatFits`, xxxLarge 세로 단일 열, 읽기 폭 680(iOS-C1). 스냅샷 Tier1/Tier2. Swift 6 strict + iOS 17 주의점 표.

**macOS·iPad** (`S0/macOS_iPad.md`) — 분기 축 = `h == .regular && v == .regular`, 플랫폼·창 폭 아님(MI-1). 루트 2개 + `TabCoordinator` 하나, 세 열은 라우트 안에서(MI-2). iPad 키보드 명령은 Mac과 공유, `PasteButton`(MI-3). 카메라 OCR 제안(MI-4 → v1.1). 17/14에서 잃는 것·폴백 표(MI-5). 화면 32장 compact/wide 표 + 스냅샷 매트릭스(MI-6). 알림 payload `aps` + `mw` + `deepLink`(MN-1), Domain watchOS(MN-2), 워치 최소 계약(MN-3), 할 것/하지 말 것(MN-4).

**Backend** (`S0/Backend.md`) — 컨텍스트 우선 패키지(B-0). EngineRouter Protocol + 어댑터 5종 + Redis 한도·브레이커 + `ai_usage`(B-1). 비용 파이프라인 `ai_usage` → `usage_daily` → cost_model(B-2, dbml v1.1 문안). 알림 payload 평면 키 + `MACOS`·`WATCHOS`(B-3 — 레드팀이 MN-1로 통일). iOS 17~25 대응: STT 부하 불변, Groq Whisper 1순위·큐 3개·사용자 일 한도(B-4 — 외부 STT는 ADR-0008로 제외). 계약 v1.1 통합 백로그 15건(B-5). S0 Day 4~5 영향(B-6).

**QA** (`S0/QA.md`) — 사실 오류 6건(hosted `macos-26` GA, `macos-14` 폐기, 공개 저장소 무료 등, 출처 보강 필요). 매트릭스 "PR = 최신 1축, 야간 = 최소 OS + 극단, 릴리스 = 전부"(QA-1), `app.yml`·`app-nightly.yml` 변경안. AI 회귀 캐시 우선·야간 40문장(QA-2). 프라이버시 카나리 5층(§2-3). reduceMotion은 `\.mwMotion` 주입(get-only 확인), 고정 px 린트 7규칙(QA-3). archify 정체 확인 + JSON 원본·PNG 커밋(QA-4). 릴리스 체크리스트 A-10~A-24.
