# 초반 BM 전략 (v1.0 — 가설만, 코드 없음)

> 근거: FD-11(사용자: "초반 BM 전략도 생각해놔야 해", "BM은 가설·베타 50·실측 비공개"), ADR-0009, `docs/council/S0/PO.md` §2(PO-2 표), `S0/REDTEAM_B.md` RT-B-09. v1.0은 **결제 없음, 전원 무료, 베타 ≤ 50명**. 계약 v1.1에 `plan`(FREE|PRO) 필드만 예약. 이 문서의 수치는 전부 **가정**이며 `eval/cost_model.py` 실측 후 갱신한다.

## ⚠ STT 원가 실측 전 주의
PO §2의 결론("STT가 MAU당 원가의 60~70%, 녹음은 유료 전용")은 `pricing_example.yml`의 **가정 단가**(외부 STT 0.006$/분)에서만 나온 것이다. 협의체 결정(ADR-0008)으로 v1.0 STT는 서버 `whisper_local`(faster-whisper, OCI A1 CPU, 0원)만 쓰므로 STT 원가는 "VM 시간 기반 CPU 분당 원가"로 다시 계산해야 하고, 그 값은 S2 실측(60초 조각이 60초 안에 끝나는지, 동시 세션 수) 전엔 없다(RT-B-09). **STT 실측 전에는 어떤 가설의 허용 원가도 확정하지 않는다.** 아래 표의 "허용 원가/MAU"는 PO-2의 가정 공식(VAT 10%, App Store 수수료 15%, 목표 매출총이익률 50%, 환율 1,400)을 그대로 옮긴 것이다.

## 3. 비용 모델 연결
- 계산기: `eval/cost_model.py`(ADR-0009). `make cost MAU=1000`이 월 원가·MAU당 원가·한계원가·손익분기 구독가·무료 한도 소진 MAU·트랙별 비교표를 출력.
- 입력: `eval/pricing.toml`(단가·무료 한도·`verified_on`·출처 URL, 미확인은 `unverified = true`), `eval/usage.toml`(가정, `source = "assumption"`), `eval/measured/usage.toml`(실측, **비공개 `.gitignore`**).
- 이 문서의 허용 원가는 `allowed_cost_per_mau_krw(list_price_krw, RevenueAssumption)`로 재계산한다. 가격·전환율·마진을 바꾸면 표의 숫자만 바뀌고 실험은 그대로.
- 갱신 리듬: 월초 스냅샷 → PR 본문에 `make cost` 표(숫자는 저장소에 남기지 않음) → 이 문서의 "가정" 표기를 실측일과 함께 갱신.

## 4. PO §2 수치 인용 (전부 **가정**, 사실 아님)
- 공통 가정: VAT 10%, App Store 수수료 15%(Small Business Program), 목표 매출총이익률 50%, 환율 1,400.
- 가설 A: 4,900/1.1 × 0.85 × 0.05 ≈ 189원/MAU 순매출 → 허용 한계원가 189원(마진 0) / 95원(마진 50%). 전환 10%면 379/189원. 유료 사용자 1인 3,786원 → 1,893원. 녹음 300분 넘으면 적자(외부 STT 가정) → 공정 사용 상한 필요.
- 가설 B: 3,000/1.1 × 0.97 × (1/0.7) ≈ 3,780원/활성 MAU → 1,890원.
- 가설 C: 1,200,000/12/1.1/30 ≈ 3,030원/MAU → 1,515원.
- PO §1-6 구조 검증 시연(`pricing_example.yml`, 가정 단가): MAU 1,000에서 api_split 1,556원/MAU(STT 65%), 녹음 0이면 187원/MAU, api_split_haiku 76원. **이 숫자는 구조 검증용이며 사실이 아니다**(PO 스스로 표기). 레드팀 정정(RT-B-08·14·15) 반영 전 값이므로 ADR-0009 계산기로 재산출해야 한다.

## 5. 되돌리는 조건
- 유료 전환율 < 2%가 3개월 → 가설 B로 무게 이동.
- STT 실측 원가가 예시의 1/5 이하 → 녹음 무료 상한 상향(가설 A 경계 재설정).
- 기업 문의 발생 → 가설 C 우선, ADR-0008의 BYOK·온디바이스 경로 전면.
- 무료 한도 소진 MAU < 베타 50 → 유료 전환 결정을 90일보다 앞당겨 협의체 소집.
