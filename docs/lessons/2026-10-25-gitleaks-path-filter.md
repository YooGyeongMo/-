# 시크릿 게이트가 계약 파일 바뀔 때만 돌고 있었다

- **무엇**: gitleaks job이 `contracts.yml` 워크플로 안에 있었고, 그 워크플로는 `paths: contracts/**` 필터라 코드 PR(#92·#94 등)은 시크릿 검사를 한 번도 안 받았다. STATE.md엔 "gitleaks 게이트"가 있다고 적혀 있었다.
- **어떻게 찾았나**: #94 머지 전 교차 확인에서 "이 PR에 gitleaks가 돌았나?"를 체크 목록으로 확인 → 체크 목록에 없음.
- **고침**: `secrets.yml`로 분리, 경로 필터 없음(모든 PR·main push). 로컬 `gitleaks git` 전체 이력 스캔 0건. 기존 오탐 1건은 스쿼시 뒤 지문이 달라져 `.gitleaksignore`에 추가.
- **배운 점**: "게이트가 있다"와 "게이트가 이 PR에서 돌았다"는 다르다. 보안 게이트에는 경로 필터를 걸지 않는다. 머지 전 확인 목록에 "어떤 워크플로가 돌았나"를 넣는다(lessons `2026-09-*` CI가 돌지 않는 네 가지 방식과 같은 계열).
